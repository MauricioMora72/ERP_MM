# ERP propio

ERP web multiempresa para empresas de servicios en Ecuador, construido sobre Google Cloud.

## Contenido inicial

- CLAUDE.md: reglas del proyecto que Claude Code lee en cada sesión.
- docs/plan-maestro.md: plan maestro exportado desde el documento del proyecto.
- docs/diccionario-de-datos.md: tablas y columnas de las fases 0 y 1.
- docs/prompt-fase-0.md: primer mensaje para Claude Code.
- db/erp_fase0_fase1.sql: esquema de base de datos, probado en PostgreSQL 16.

## Cómo empezar

1. Abra Claude Code sobre este repositorio.
2. Pegue como primer mensaje el contenido de docs/prompt-fase-0.md.
3. Revise el plan que Claude Code le proponga y dé su visto bueno antes de que empiece a construir.
